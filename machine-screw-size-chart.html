Machine screw size chart

A #8 machine screw is 0.1640 in across; #8-32 UNC takes a #29 tap drill.

Numbered sizes follow the formula 0.060 + 0.013 x number, so #10 is 0.190 in. Coarse (UNC) is the default; fine (UNF) has more threads per inch. #0 only has a fine thread. Clearance holes for each size are in the drill finder.

How to read a machine screw size

A size such as #8-32 UNC has three parts: the gauge number (8), the threads per inch (32) and the thread series (UNC, unified coarse). Sizes up to #12 use gauge numbers; from 1/4 inch up they are written as fractions, for example 1/4-20. Each gauge number maps to a diameter by 0.060 + 0.013 x number, so #8 is 0.164 in.

UNC or UNF?

Coarse threads (UNC) are the default: they assemble faster and are less likely to cross-thread. Fine threads (UNF) give finer adjustment and are used where the wall is thin or the load is better spread over more threads. For the same diameter the two are not interchangeable, so match the thread count printed on the part: 1/4-20 is coarse with a #7 tap drill, 1/4-28 is fine with a #3.

Tap drill or clearance hole?

Drill the tap drill size in the part you will thread. Drill the clearance hole in the part the screw passes through. Close, normal and loose fits trade alignment against how forgiving the holes are to position. A common mistake is using the clearance drill in the part you meant to tap, which leaves nothing for the thread to cut.
