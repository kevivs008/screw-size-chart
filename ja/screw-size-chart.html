適切な表の選び方

まず、ねじの表記を見てください。M のあとに数字があればメートルねじです。# 記号または 1/4 のような分数はインチサイズです。先端が鋭い円錐形で、ねじ山が深ければ、ほぼ間違いなく木ねじです。種類ごとに分けているのは、同じ数字でも種類によって意味が違うからです。#8 は小ねじでも木ねじでも 0.164 in ですが、ねじ山、タップ下穴径、通し穴は異なります。

ねじが手元にあるだけなら、ノギスでねじ山の外側を測り、ドリル径のページの「手持ちのねじを調べる」を使ってください。頭ではなくねじ山の山頂を測り、わずかな誤差を見込んでください。

小ねじのサイズの読み方

#8-32 UNC のようなサイズは三つの部分でできています。番号(8)、インチあたりの山数(32)、ねじ山の系列(UNC、ユニファイ並目)です。#12 までは番号で、1/4 インチ以上は分数で表します(例:1/4-20)。番号と直径の関係は 0.060 + 0.013 x 番号 で、#8 は 0.164 in です。

UNC と UNF のどちらか

並目(UNC)が標準で、組み付けが速く、斜めにかみ込みにくい特長があります。細目(UNF)は細かい調整ができ、壁が薄い場合や、より多くの山に荷重を分散したい場合に使われます。同じ直径でも互換性はないので、部品に印字された山数に合わせてください。1/4-20 は並目でタップ下穴径は #7、1/4-28 は細目で #3 です。

タップ下穴径か通し穴か

ねじ山を切る部材にはタップ下穴径のドリルであけます。ねじが通り抜ける部材には通し穴をあけます。精密、標準、ゆるいのはめあいは、位置合わせと穴の位置公差のどちらを重視するかの違いです。よくある間違いは、ねじ山を切るはずの部材に通し穴用のドリルを使うことで、これではねじ山を切る材料が残りません。

番号と直径

木ねじの番号は、番号付きの小ねじと同じ計算に従います。インチ直径は 0.060 + 0.013 x 番号 で、#8 は 0.164 in です。頭の形と長さは番号とは別です。

下穴か通し穴か

下穴は、ねじがかみ込む側の板にあけます。ねじ山の内側の軸径くらいにすると、ねじ山が切る木材が残り、木が割れません。硬材では軟材より大きくします。#8 のねじでは、表は軟材に 7/64、硬材に 1/8 を示しています。通し穴は上側の部材にあけ、ねじが自由に通って接合部がしっかり締まるようにします。

穴の試し方

硬さは樹種により、同じ樹種でも板により異なるため、公表されている表は食い違います。まず端材で下穴を試してください。ねじが締まりにくい、または木が割れる場合はドリルを一段大きくし、ねじが空回りする場合は一段小さくします。

小ねじと木ねじの違いとは?

小ねじ(機械ねじ)は、まっすぐな軸に規格化されたねじ山を持ち、ナットやめねじ(ねじ穴)と組み合わせて使うねじです。木ねじは、先が細く尖った円すい状の軸と粗いねじ山を持ち、木の繊維の中を自分で切り進みます。頭の下には、ねじ山のない平らな首部があるのが一般的です。サイズ番号は重なっていて、そこが落とし穴です。どちらの #8 も直径は 0.164 in ですが、必要な穴は違います。ねじの種類ごとに専用の表があるので、手元のねじに合わせて小ねじのサイズ表か木ねじのサイズ表を使い、もう一方の表は使わないでください。

要点

  • 小ねじは、合わせるめねじ(ナットまたはねじ穴)が必要です。木ねじは、木の中に自分でねじ山を作ります。
  • 見分けのヒント:頭の下に平らな首部があり先端が尖っていれば木ねじ、全長にねじ山があり先端が平らなら小ねじです。
  • 同じサイズ番号でも、必要な穴は違います。#8 の小ねじは #29 のドリルでタップ下穴をあけますが、#8 の木ねじには木の種類に合わせた下穴をあけます。
  • もう一方の種類の表から、穴の寸法を借りてはいけません。

ねじ山の違い

小ねじのねじ山は平行(ストレート)で、直径は一定、先端は平らか面取りされています。ねじ山は規格のシリーズに属します。統一インチねじ(UNC と UNF、ASME B1.1)か、ISO メートルねじです。ねじが同じ規格で切られた、または成形されたねじ山と組み合わせることを前提にしているため、規格のシリーズが重要になります。たとえば #8-32 の小ねじは、どの #8-32 のナットやねじ穴にも合います。

木ねじには、合わせるべき相手のねじ山がありません。ねじ山は深く間隔が広く、軸は先端に向かって細くなっているのが普通です。そのため木に食いつき、自分で中へ進んでいけます。木ねじは ASME B18.6.1 で扱われており、切削ねじの木ねじでは、ねじ部の長さを呼び長さのおよそ3分の2と定めています。それより下は平らな軸です。

補足です。すべての木ねじが先細りというわけではありません。昔ながらの木ねじは、軸の太さがねじ山の外径と同じで、テーパー付きのドリルと組み合わせます。最近の量産ねじの多くは、ねじ山の外径よりわずかに細いストレートな軸を持ち、ストレートなドリルで足ります。どちらも木ねじで、後者はドリルの選び方に寛容なだけです。

それぞれの固定のしくみ

小ねじは、相手のねじ山とのかみ合いで固定します。ナットやねじ穴の中で、ねじのねじ山とめねじが噛み合い、締めることで部材同士が押さえ付けられます。

木ねじは、ねじ山が下側の部材の木の繊維に食い込むことで固定します。頭の下の平らな軸には意味があります。2枚の板をつなぐとき、軸は上の板の通し穴を通るため、ねじ山は下の板だけに噛み、締めると2枚が引き寄せられます。ねじ山が上の板にも噛むと、板同士が離れたままになることがあります。

それぞれの使い道

小ねじは、相手のねじ山がある場所で使います。金属のねじ穴、ナット、家電のパネル、電子機器、機器の筐体などです。木ねじは、木材と、合板やパーティクルボードのような木質ボードに使います。小ねじを素の木に入れても、噛み合う相手がありません。木ねじをねじ穴に入れても、ねじ山の形が合いません。互換性はないのです。

第3のグループとして、板金ねじやタッピンねじがあります。両者の中間にあたり、このガイドの対象外です。同じルールが当てはまります。実際に手元にある種類の表を使ってください。

同じサイズ番号でも穴が違う理由

混乱の元は番号の付け方です。#8 の小ねじの呼び外径は 0.164 in(4.166 mm)で、#8 の木ねじに示されている呼び径も 0.164 in です。番号が示すのはねじの大きさだけです。穴については何も示しません。穴は、その穴が果たす役割で決まります。

#8 の小ねじ(8-32 UNC)タップ下穴径は #29(0.136 in / 3.454 mm)。そのあとタップでねじ山を切る通し穴(密な嵌め合い)は #18

小ねじの数値は、そのねじ山についての規格値です。木ねじの数値は、メーカーの下穴の目安(概算値と明記されています)から引いた一般的な目安です。木の硬さ、含水率、ねじのメーカーによって変わるので、端材で試してください。2つの種類を混ぜないでください。#29 の穴は 0.136 in で、硬材の一般的な下穴 1/8 in(0.125 in)よりはるかに大きく、木ねじのねじ山が切り込む木がほとんど残りません。

手に取って見分けるには

  • 軸:頭の下にねじ山のない平らな部分があれば、木ねじです。
  • 先端:鋭く尖っていれば木ねじ、平らか丸ければ小ねじを思わせます。
  • ねじ山の間隔:広くて粗ければ木ねじ、細かく均一なら小ねじです。
  • はめ合わせ:小ねじは同じサイズのナットに抵抗なく回って入りますが、木ねじは入りません。
  • ノギス:ねじ山の頂を測ります。木ねじの平らな軸は、呼び寸法よりわずかに大きく出ることがあります。

どちらが必要か

決め手は材料です。ねじの行き先がねじ山(ナット、金属のねじ穴)なら、サイズとねじ山シリーズが合う小ねじが必要です。木材や木質ボードなら、木ねじが必要です。荷重を受ける固定や安全に関わる固定では、一般的なガイドではなく、設計者またはメーカーの仕様に従ってください。ねじサイズ表のハブページでは、3つのグループを並べて確認できます。

数値の根拠となる規格は、統一ねじの ASME B1.1、小ねじの ASME B18.6.3、木ねじの ASME B18.6.1 です。木材用の穴の寸法は、木ねじのサイズ表によります。このサイトが数値をどのように確認しているかは、出典と方法で説明しています。

UNC と UNF ねじ山の違いとは?

UNC(並目)と UNF(細目)は、同じねじ径に対する2つのねじ山シリーズです。どちらも ASME B1.1 で定められており、60°のねじ山形状は共通です。違うのは、1インチの間にねじ山がいくつ入るかだけです。直径 1/4 in のねじは、並目シリーズでは 1/4-20、細目シリーズでは 1/4-28 になります。並目はねじ山の数が少なく深く、細目は数が多く浅いのが特徴です。両者に互換性はなく、タップ下穴径もシリーズによって変わります。手元にねじがあるなら、1インチあたりのねじ山数を数えてから、小ねじのサイズ表でサイズを調べてください。

要点

  • UNC と UNF は直径が同じで、1インチあたりのねじ山数(TPI)が違います。1/4-20 と 1/4-28、#8-32 と #8-36、#10-24 と #10-32 がその例です。
  • UNC のねじは UNF のナットに入らず、逆も同様です。確実に見分けられる方法は、TPI を数えることだけです。
  • タップ下穴径はねじ山に応じて変わります。細目シリーズでは、やや大きいドリルが必要になるのが一般的です。
  • 細目と並目のどちらが作業に向くかは、設計上の判断です。経験則ではなく、図面や仕様書に従ってください。

UNC と UNF が意味するもの

この文字は Unified National Coarse と Unified National Fine の略で、統一インチねじ方式の2つの主要シリーズの名前です。各直径にはシリーズごとに規格化された TPI があるため、「1/4-20」「1/4-28」は直径と TPI を並べた完全な呼び方です。外ねじなら 1/4-20 UNC-2A のように、シリーズとはめあい等級を添えた表記もよく使われます。2A(おねじ)または 2B(めねじ)の部分がはめあい等級で、部品同士の嵌まり具合を決めます。ごく小さいサイズの一部は片方のシリーズしかありません。たとえば #0 は 0-80 のみが作られています。

シリーズでタップ下穴径が変わる理由

タップ下穴径は、タップが適切な深さのねじ山を切れるだけの材料を残す大きさで、細目のねじ山は浅くなります。そのため、細目シリーズの穴はねじの全径に近くなります。ねじ山の深さ約 75% を狙う一般的な近道の式は、タップ下穴径 ≈ 外径 − 0.975 ÷ TPI です。1/4-20 なら 0.2500 − 0.975 ÷ 20 = 0.2013 in で、#7(0.201 in)に当たります。1/4-28 なら 0.2500 − 0.975 ÷ 28 = 0.2152 in で、#3(0.213 in)に近くなります。#8 では、2つのシリーズがたまたま同じ #29(0.136 in)に落ち着くため、1本のドリルで両方に対応できます。

細目ねじが選ばれるとき

設計者が細目シリーズを選ぶ理由は、幾何学的なものに集約されます。ねじは1回転でピッチ1つ分進み、20 TPI なら 0.0500 in、28 TPI なら 0.0357 in です。つまり細目なら、より細かい調整ができます。短い部分や薄い部分では、同じ深さに細目のほうが多くの山を収められます。深さ 1/4 in のかみ合い部には、20 TPI で5回転分、28 TPI で7回転分が入ります。そして多くの場合は、単に図面が UNF を指定しているだけです。

「細目のほうが強い」「振動に強い」「並目のほうが頑丈」といった説明を目にすることもあるでしょう。それが重要かどうかは、材料、接合部、仕様によって変わるため、このガイドでは優劣をつけません。荷重を受ける用途や安全に関わる用途では、仕様に従うか、資格のある技術者に相談してください。

並目が標準になる場面

並目は汎用のシリーズです。金物の大半はこのシリーズで作られており、手で締め始めやすく、浅い細目ねじよりも、ねじ山の小さな傷や多少の汚れに強い傾向があります。図面に別の指定がなく、部品に並目のねじが付いていたなら、交換用も並目である可能性が高いでしょう。ただし、数えて確認してからにしてください。

どちらか見分ける方法

  1. ノギスで外径を測り、サイズ(番号サイズか分数)を特定します。
  2. 1インチあたりのねじ山数を数えるか、歯の間に光が漏れないピッチゲージの刃を探します。
  3. 数えた値を、上の表か全表と照らし合わせます。

ナットは手で試してください。1〜2回転入ってから引っかかるなら、そこで止めます。シリーズが違っており、無理に回すと両方のねじ山を傷めます。メートルねじも考え方は同じで、並目ピッチが標準(M8 x 1.25)、細目ピッチは呼び方の中に示されます(M8 x 1)。

インチサイズの一覧は小ねじのサイズ表をご覧ください。手元のねじがどの種類か分からない場合は、ねじサイズ表のハブページから始めてください。

各シリーズは ASME B1.1 で定められています。タップ下穴径は、ねじ山 75% の標準表に基づきます。数値の確認方法は、出典と方法で説明しています。
